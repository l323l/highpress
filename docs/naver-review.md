# 네이버 로그인 검수 신청 준비

네이버 개발자센터에서 애플리케이션을 "개발 중"에서 "서비스 적용"으로 바꾸려면 검수를 받아야 합니다.
검수 전에는 애플리케이션을 등록한 네이버 계정(과 멤버관리에 넣은 계정)만 로그인됩니다.

아래 기준은 네이버 로그인을 붙여 본 사람들의 글과 쇼핑몰 호스팅 업체의 안내를 모은 것입니다.
네이버 공식 검수 가이드는 직접 열어 확인하지 못했으니, 신청 화면에 보이는 안내가 이 문서와 다르면 그 안내를 따릅니다.

2026-10-14 에 v0.20.0 · 새 주소(`https://app.high-press.workers.dev`) 기준으로 다시 맞췄습니다.
v0.20.0 부터 네이버 로그인을 **가입 · 로그인**과 **카페에 올리기** 두 곳에 씁니다.

## 신청하기 전에 할 일

1. **실제로 해 보기 (두 가지).**
   - 네이버로 가입: 배포 주소에서 `로그인 · 가입` → `네이버로 로그인` → 닉네임을 정하고 약관에 동의. 가입되고, 로그아웃한 뒤 다시 네이버로 로그인하면 같은 계정으로 들어오는지 봅니다.
   - 카페에 올리기: 글쓰기 → 내보내기 → 게시판 주소를 넣고 `네이버 로그인하고 카페에 올리기`. 글이 올라가고 한글이 깨지지 않는지 봅니다.
   둘 중 하나라도 안 되면 검수를 신청할 단계가 아닙니다.
2. **제공 정보를 최소로 줄이기.** 개발자센터 → 내 애플리케이션 → API 설정 → 네이버 로그인의 "제공 정보 선택"에서
   이름·이메일·별명·프로필 사진 같은 항목을 모두 끕니다. 이 앱이 쓰는 것은 항목을 고르지 않아도 늘 내려오는 회원 식별자(id) 하나와 카페 글쓰기 권한뿐입니다.
   항목을 켜 두면 검수에서 "그 정보를 어디에 쓰는지" 화면을 요구하고, 설명하지 못하면 반려됩니다.
   끌 수 없는 필수 항목이 있으면 아래 "제공 정보 활용처" 문구를 씁니다.
3. **주소 바꾸기 (가장 먼저).** 사이트 주소가 바뀌었으므로 개발자센터 → 내 애플리케이션 → API 설정에서
   서비스 URL 을 `https://app.high-press.workers.dev`, Callback URL 을 `https://app.high-press.workers.dev/naver-callback` 으로 바꿉니다.
   예전 주소(`…jawon2517.workers.dev`)는 지웁니다. 이걸 바꾸지 않으면 네이버 로그인 창에서 오류가 나서 1번을 할 수 없습니다.
   서버 쪽 허용 주소(`APP_ORIGINS`)는 이미 새 주소로 바꿔 두었습니다.
4. **화면 캡처 두 장을 직접 찍기** (아래 표의 4번, 6번). 네이버의 화면이라 대신 찍을 수 없습니다.

## 신청서에 적을 문구

신청 화면의 칸 이름은 다를 수 있습니다. 뜻이 같은 칸에 넣습니다.

**서비스 이름**: HIGH PRESS (하이프레스)

**서비스 설명**

> 축구 칼럼을 쓰는 사람을 위한 글쓰기 도구입니다. 글, 스탯 표, 전술 그림을 한 화면에서 만들고, 완성한 칼럼을 네이버 카페에 올릴 수 있습니다.
> 가입한 사람들이 올린 칼럼은 로그인하지 않아도 읽을 수 있고, 글쓰기와 네이버 카페 올리기는 가입한 뒤에 쓸 수 있습니다. 무료이며 광고가 없습니다.

**네이버 로그인을 쓰는 곳과 목적**

> 두 곳에 씁니다.
> 1) 회원 가입과 로그인: 첫 화면 오른쪽 위 "로그인 · 가입"을 누르면 뜨는 창에서 "네이버로 로그인"을 누르면 네이버 로그인 창이 열리고, 네이버 계정으로 가입 · 로그인됩니다(Google 계정으로도 가입할 수 있습니다).
> 2) 네이버 카페에 올리기: 글쓰기 화면의 "내보내기 → 네이버 카페에 바로 올리기"에서 "네이버 로그인하고 카페에 올리기"를 누르면, 사용자가 쓴 칼럼을 자신의 네이버 계정으로 자신이 가입한 카페에 올립니다.

**카페 API 를 쓰는 목적**

> 사용자가 고른 카페의 게시판에, 사용자가 쓴 칼럼(제목, 본문, 사진)을 사용자의 이름으로 등록합니다.
> 사용자가 단추를 누를 때 한 편씩만 등록합니다. 자동 등록, 예약 등록, 여러 카페에 한꺼번에 올리기, 글 수집 기능은 없습니다.
> 카페 가입 API 는 쓰지 않습니다.

**제공 정보 활용처**

> 네이버 회원 식별자(id) 하나만 씁니다. 같은 사람이 다시 로그인했을 때 같은 계정으로 들어오게 하는 데에만 쓰며, 되돌릴 수 없게 바꾼 값(SHA-256)으로 보관합니다.
> 이름, 이메일, 별명, 프로필 사진 등 그 밖의 회원 정보는 받지 않고 쓰지 않습니다. 서비스 안의 닉네임은 사용자가 직접 정합니다.
> 네이버가 발급한 접근 토큰은 서버에 저장하지 않습니다. 가입 · 로그인 때는 확인에 쓰고 바로 버리고, 카페에 올릴 때는 사용자의 브라우저 탭이 열려 있는 동안에만 메모리에 둡니다.

**검수 담당자가 직접 해 보는 방법**

> 1. https://app.high-press.workers.dev 에 접속합니다. 첫 화면(피드)은 로그인 없이 보입니다. 오른쪽 위 "로그인 · 가입"을 누르고 "네이버로 로그인"을 누릅니다. 네이버 로그인 창(팝업)에서 동의하면 창이 닫히고 로그인됩니다. 이어서 오른쪽 위 "가입 마치기"에서 닉네임을 정하고 약관에 동의합니다.
> 2. 화면 아래 가운데의 + 단추를 눌러 글쓰기 화면으로 가서 제목과 본문을 적습니다.
> 3. 오른쪽 위 "내보내기"를 누르면 열리는 창의 아래쪽에 "네이버 카페에 바로 올리기"가 있습니다. 처음에는 유의사항 안내가 한 번 뜨며 "알겠습니다"로 닫습니다.
> 4. 글을 올릴 카페 게시판의 주소(예: https://cafe.naver.com/f-e/cafes/숫자/menus/숫자)를 붙여 넣고 초록색 "네이버 로그인하고 카페에 올리기"를 누릅니다.
> 5. 네이버 로그인 창(팝업)에서 "카페 글쓰기"에 동의하면 글이 등록되고 "올린 글 보기" 링크가 나옵니다. 팝업이 막혀 있으면 허용해 주세요.
> 글은 로그인한 네이버 계정이 가입해 있고 글을 쓸 수 있는 게시판에만 올라갑니다.

## 반려될 수 있는 점과 대비

- **가입자 상한.** 지금 가입자는 50명까지입니다(`max_users`). 상한에 닿아 있으면 검수 담당자가 가입하지 못해 반려됩니다. 신청 전에 `select count(*) from public.profiles;` 로 여유를 확인합니다.
- **로그인 단추 모양.** 네이버는 로그인 단추가 네이버의 단추 모양을 따르기를 요구하는 것으로 알려져 있습니다. 초록 바탕에 흰 N 과 글자로 맞췄지만, 네이버가 내려 주는 공식 단추 그림을 쓰지는 않았습니다. 이 점으로 반려되면 공식 그림으로 바꿉니다.
- **탈퇴와 연동 해제.** 회원 탈퇴를 하면 서비스의 계정은 바로 지워지지만, 네이버 쪽의 연결(네이버 → 내정보 → 연결된 서비스)은 자동으로 끊지 않습니다. 검수에서 이를 요구하면 탈퇴할 때 네이버 연동도 함께 해제하도록 고칩니다.
- **주소의 `#`.** 방침·약관 주소에 `#/` 이 들어갑니다. 주소 칸이 이를 받지 않으면 서비스 첫 화면 주소를 넣고 "메뉴 → 약관과 고지에서 볼 수 있음"이라고 적습니다.
- **무료 호스팅 주소.** `workers.dev` 주소를 문제 삼으면 자체 도메인이 필요할 수 있습니다(유료). 그때 다시 정합니다.

## 신청하는 곳

네이버 개발자센터 → Application → 내 애플리케이션 → 해당 애플리케이션 → **네이버 로그인 검수 상태**(또는 "검수 요청") 에서 신청합니다.
결과는 등록한 메일로 오고, 영업일 기준 3~4일이 걸린다고 합니다. 반려되면 사유에 맞춰 고친 뒤 다시 신청하면 됩니다.
